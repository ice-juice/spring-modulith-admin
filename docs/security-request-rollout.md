## 回执边界

通用账本只记录调用者自己的操作状态，不缓存私信正文、个人资料、密码或业务DTO。再次获取业务详情必须使用原接口重新执行当前对象/租户权限判断；撤销操作权限后不能读取其回执。已删除对象的历史操作状态不等于允许读取被删除对象。该最小元数据原则用于处理“提交成功但响应丢失”，不能借此提供跨用户/跨租户的工作查询。

异常必须区分：429超频、409同键异参或对象忙、202处理中/结果未知、可确认回滚的失败、503未受理。网络超时/5xx本身不是业务回滚证明。原键查询不需要原密码或表单正文；随机键不是身份凭据，仍须验证当前调用者与权限。

B1客户端兼容改动仅在两套独立API客户端为POST/PUT/PATCH/DELETE缺省补随机Idempotency-Key，保留显式原键；当前不等于S1c的在途合并/UNKNOWN恢复。旧版 `frontend/src/api/http.ts` 已审阅为3行新增、无其他修改，新增独立协议单测；只更新该文件的已审阅基线哈希，不重置其他旧版差异。

- 消息写入使用模块事务，外部效果通过既有事件；SocketTicket不是可缓存的普通响应。
