# 新版规则界面开发总结

本次在 `frontend-next` 完成F0～F4共8项，沿用已验收的鸢尾紫柔光主题、18px紧凑标题和现有管理组件。逐项结果见[进度](progress.md)和[验证证据](frontend-evidence.md)。

- 专业人员：创建场景与模板，在同一工作区配置Monaco表达式、递归条件组、Vue Flow流程或决策表。支持参数Schema、阶梯区间、断言、模拟诊断与路径定位，保存草稿后独立发布。可查看历史、差异、影响，复制、废弃或撤销模板。
- 运营人员：按场景选择命名的固定版本模板，填写带帮助的参数和业务对象，实例先试算再发布；支持停用、回滚以及对比升级后保存新草稿。目录不加载编辑器。
- 治理人员：维护保存用例、批跑及版本对比，查看批量迁移回执、执行详情与统计，按授权清理过期记录及空闲缓存。
- 工程：后端仅补充兼容的只读查询和现有权限菜单登记。金额保留十进制精度，大整数ID以字符串使用，前端草稿、模拟值及画布状态不写浏览器持久存储；提交未知不自动重试。

验收：前端 `npm run verify`（52单测），规则浏览器16/16、静态产物15/15、隔离真实后端1/1；后端菜单/规则/架构专项42项，全部通过。真实链路覆盖登录、创建、模拟、发布、目录和未授权绑定拒绝；业务接入成功仍需归属模块提供 `RuleBindingPolicy`。未部署生产、未覆盖历史ZIP；其他模块原有浏览器全套不属于本轮专项核验。

可查看[桌面模板编辑](rule-template-light-desktop.png)及[手机深色目录](rule-catalog-dark-mobile.png)。入口和复验方式见 [新版前端README](../../frontend-next/README.md#规则界面)。
