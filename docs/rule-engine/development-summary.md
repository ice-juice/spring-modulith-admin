| B3 | 决策表 UNIQUE / FIRST、默认输出与冲突检查；表格进入流程；阶梯区间参数；模板复制、版本差异、影响清单与升级预览 / 草稿迁移 |
| B4 | 保存用例、版本对比、带摘要的发布测试门禁；逐项事务批量草稿迁移及中断恢复识别；执行详情 / 检索 / 统计、资源提示与保留清理；模板废弃 / 撤销和传递依赖影响 |

后端根包提供 `RuleExecutionApi`，业务模块通过 `common::security` 的 `RuleBindingPolicy` 授权对象绑定。没有默认业务对象放行，真实商品 / 活动模块尚未接入；折扣计算在测试中使用受控对象与真实 HTTP / MySQL 完成验证。

保存草稿不改变线上规则；模板升级不自动重绑实例；批量迁移不自动发布；业务绑定和计算都读取当前已发布快照。实例必须先试算再发布，模板发布必须通过文档断言与全部启用用例。失败的发布报告独立保留，不影响原生效指针。

## 数据与工程变更

- 规则生产代码位于 `backend/src/main/java/com/sma/admin/rule/`；管理接口统一 `/api/rule`。新增业务授权SPI、逻辑权限目录与双语言文案，不创建空前端菜单。
- Flyway V1～V4 创建资产、版本、发布、执行、租户写锁、用例、测试报告和迁移回执，并增加发布证明关联与执行发布修订。版本与发布历史不可原地覆盖。
- 专用 Jackson3 保留十进制并拒绝未知字段；兼容旧简写Schema与既有构造器，未更改全局 JSON 规则。
- 后端POM增加两项内核依赖及可选验证输出目录。两个既有元数据测试改为精确校验已配置且符合白名单的测试库，保留清库安全保护。
- 本次没有改动规则前端源码或安装 Vue Flow / Monaco；工作区其他前端与扩展模块变更属于其他在途工作。

## 验证与实际发现

逐阶段测试覆盖表达式、条件、流程、决策表、参数约束、固定依赖、真实数据库、真实管理员令牌与 HTTP、操作审计、并发修订、幂等、租户与业务授权。最终还运行后端及其依赖 reactor 的全量 Maven verify、Modulith、架构和语言包检查；具体次数及最终结果记录在证据文件，未通过的运行保留失败记录。

原生 QLExpress timeout 未及时结束无限循环。平台采用解析阶段能力白名单，拒绝循环、赋值、声明、lambda、Java 类与方法、宿主Bean；不把原生超时称为硬沙箱。测试验证拒绝非法表达式，未再次执行原生无限循环。

性能测量将纯计算与真实HTTP样本分开；记录本机首次编译、缓存命中、表达式 / 流程 / 200行决策表的顺序耗时，不能据此承诺生产QPS。在途租约清理、过期记录清理、发布证明保留、版本完整性异常、传递撤销与遗留迁移批次识别均有专门验证。
