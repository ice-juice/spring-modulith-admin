# 我的随手栏

新版管理端顶部工具栏的“我的随手栏”入口包含常用标签和个人便签，默认展开右侧抽屉。入口在正常工具栏布局中，不再悬浮覆盖表格操作按钮。数据属于当前租户、门户及账号，重新登录或换电脑后可读取服务端保存的内容。

## 常用标签

- 页面标题旁点击图钉收藏；工作页签的省略号菜单也提供固定/取消固定。
- 随手栏“添加”从本人可访问的页面中选择。标签最多30个，同一页面不会重复添加。
- 拖动手柄排序，或使用上移/下移按钮；铅笔按钮修改个人名称，留空恢复页面名称。
- 点击标签打开页面，当前页面高亮。关闭工作页签不取消收藏；取消收藏不会关闭正在编辑的页面，并提供8秒撤销。
- 页面已有工作页签时，切换到该页签并保留其当前筛选地址；没有工作页签时打开默认入口。这不会把临时筛选条件写入收藏。
- 菜单改名/路径调整按稳定ID解析；无权或失效的入口无法点击。收藏不保存筛选参数、表单或业务记录。

## 便签

- “新建文字便签”或“新建清单”开始记录，可选择关联当前页面；清单可勾选并折叠已完成项。
- 停止输入约1秒自动保存，状态显示保存中/已保存/未保存，也可立即保存。标题最多50字、正文10000字、清单100项，使用中最多200张。
- 支持搜索标题/正文/清单、列表置顶、颜色、复制全文和关联页面回跳。清单完成仅更新个人记录，不执行业务动作。
- 归档后只读，可恢复编辑；删除进入回收站，30天内可以恢复。超过期限不可恢复，正文在本人下次打开列表时清理。
- 保存失败时文本保留，并停止自动重试；恢复网络后点击重试，先核对服务端结果。版本冲突时可查看远端版本、采用远端或将本次编辑另存为新便签。
- 未保存内容会阻止关闭面板或主动退出账号；关闭浏览器会触发离开提醒。切换业务页面保留编辑。强制退出/切换账号会清除原身份内存，因此不能当作离线笔记使用。
- 锁屏状态不能保存便签；此时主动退出会明确提示未保存修改将丢弃，可取消并解锁保存。通过账号菜单修改密码前也会检查便签保存结果。

## 显示方式

在面板“显示方式”选择：

| 方式 | 行为 |
|---|---|
| 右侧抽屉 | 点击入口展开，关闭按钮、外部区域或Esc收起；保存失败时保持可见 |
| 悬浮面板 | 跨页面常驻；标签先显示6项，可展开更多 |
| 固定侧栏 | 宽屏给内容区让出380px；不足1280px回到抽屉 |

便签可以单独“悬浮显示”，最多同时3张。关闭浮窗只收起窗口，不删除便签。窗口支持拖动吸附左右边缘、右下角缩放、折叠标题条和恢复默认位置。移动/缩放按钮获得焦点后可使用方向键。

小于768px统一在抽屉内操作，桌面浮窗状态保留到返回宽屏。显示方式保存到服务端；窗口位置、大小、折叠状态、浮窗选择和最后分区保存在本设备，按身份隔离，不保存便签正文。锁屏时不显示正文。
