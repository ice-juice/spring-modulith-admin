# 新前端设计规范 v1.0

状态：设计规范及实现已通过本地浏览器验证。对应 P04 R0-03 / R1-02 / R6-02，2026-11-11。

## 设计取向

青绿色主色、中性浅色背景、独立内容表面和清晰排版。侧栏采用与内容同一主题的表面，选中菜单使用浅强调色。主要按钮、状态和页面层级有统一语义，减少全页高饱和色与重复卡片边框。

## 已落地的变量

变量实现位于 `frontend-next/src/styles/theme.css`，浅色与深色分别配置。基础间距 4px；页面边距桌面 28px、窄屏 16px；正文 14px；页面标题 24px；控件常用高度 36px；标准/紧凑表格以垂直内边距区分，允许内容自然增高。

`primary` 表示主要行动，`accent` 表示轻强调与选中，`muted` 表示次级区域，`destructive` 表示破坏性行动。状态额外使用 success/warning。状态文字和提示不只靠颜色表达。

## 框架与页面结构

- 桌面侧栏 248px，收起 76px；小于 lg 断点时改为抽屉导航。
- 顶栏包含面包屑、消息、显示设置和用户菜单；业务顶部导航和工作标签独立分层。
- 页面顺序为标题与主要操作、筛选、列表/内容、分页。
- 数据表格保持局部横向滚动，行操作使用清晰文字按钮或菜单。
- 编辑弹窗使用受视口约束的容器：标题和操作区保持可见，正文独立滚动。
- 滚动区域使用透明轨道及主题色圆角浮动滑块，悬停/操作时出现、离开淡出；键盘聚焦时可见。主导航、顶部导航/标签及数据表格使用统一 ScrollArea，其他区域使用细滚动条兜底。
- 顶栏主题与语言设置分开：主题独立入口显示当前模式图标，语言和时区共用另一个入口。

## 三类设计样板

开发态入口 `/dev/components`：

1. 用户管理：头像缩写、身份信息、状态、行操作、选择、分页与编辑表单。
2. 角色授权：角色侧区、可搜索的权限树、保留隐藏勾选、选择计数和操作区。
3. 工作台：业务统计、待处理事项及快捷入口。

样板数据为 `example.test` 等独立模拟内容，不调用真实写接口。它们用于验证基础组件与设计，不能作为真实业务实现的验收证据。实际工作台已另接现有 `/workspace/dashboard`，独立真实后端联调已验证。

## 国际化与主题

已有 zh-CN/en-US 资源迁入新工程，公共框架语言先行加载；基础组件关闭按钮纳入语言切换。主题在 HTML 首屏尽早恢复，应用状态随后接管。深色模式使用独立语义色。

## 完成的设计检查

- 三类实际页面覆盖 1920/1440/1024/768/390/320px，中英文、明暗主题共 72 种组合。
- 保存 24 张实际页面截图（1440px 和 390px），加上原有 5 张独立组件样板截图。测试数据和视觉测试时钟固定，可用作后续视觉比较的基线。
- 视觉抽查：中文浅色用户页、英文深色角色页、英文深色移动工作台及组件样板。布局、分页、行操作和长页面未见遮挡或文档级横向溢出。英文截图中的中文菜单、用户名和业务标题来自固定后端测试数据；前端按服务端返回内容展示。
- 三类实际页面的两种语言和主题执行自动 AA 规则检查；双倍 CSS 缩放、长表单操作区、焦点约束/返回、Escape 和移动端行操作另有专项测试。
- 表单校验、失败保留草稿、取消/未保存确认、头部偏好同步、文件/头像、附件选择及富文本使用统一组件。
