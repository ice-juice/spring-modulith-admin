# Springboot Modulith Admin 用户手册

版本：2026-11-10。本手册面向后台使用者与管理员，按当前系统页面编写。具体巡检和未验证边界见 [浏览器巡检记录](browser-audit.md)，安装与维护见 [开发手册](developer-manual.md)。

## 1. 登录与日常入口

本机开发入口为 <http://127.0.0.1:5173/>。正式环境使用管理员提供的网址。

1. 输入管理员分配的用户名、密码；启用验证码时填写图片中的字符。
2. 验证码看不清时点击图片刷新。登录失败后验证码会刷新，需要重新填写。
3. 按需选择“保持登录”，点击“登录”。系统通常进入操作台；从受保护页面跳转来登录时会返回原页面。
4. 顶部“退出登录”结束当前登录。仅关闭标签页不等于主动退出。

系统没有通用默认密码。首次安装需要维护人员初始化管理员，已有账号的密码不会因重新初始化而改变。账号或验证码错误时按页面提示处理；账号权限问题联系管理员。

### 页面基本操作

| 位置 | 用途 |
|---|---|
| 左侧菜单 | 展开目录后进入页面；搜索框按菜单名称筛选。 |
| 左上角菜单按钮 | 收起为图标导航或展开；窄窗口下展开的导航覆盖在内容上方，可点击遮罩关闭。 |
| 顶部导航“全部”及自定义入口 | 限定左侧显示哪些一级菜单；“全部”恢复所有有权访问的菜单。 |
| 页面标签 | 切换已经访问的页面，关闭非首页标签。同一页面更新筛选条件时复用原标签。标签记住页面地址，不保证保留尚未保存的表单。 |
| 顶部铃铛 | 消息中心；角标汇总未读通知、待处理待办和未读私信。 |
| 顶部姓名 | 个人资料。 |
| 语言、时区 | 立即切换；登录后会保存到个人偏好。 |

菜单和按钮由权限决定，看不到某项功能不一定是页面故障。能进入页面也不代表有新增、编辑、删除或授权权限。服务器会再次校验操作权限和数据范围。

## 2. 操作台

操作台显示当前账号有权查看的统计、系统健康状态、当地时间、后台入口、待处理事项和快捷入口。

- 点击统计卡片进入相应列表。
- 点击待处理事项进入对应通知或待办详情。
- 快捷入口来自当前账号菜单，最多显示前八项。
- 统计为零表示当前可见范围内没有相应记录；异步加载期间应等待加载完成。
- 系统状态异常时先由维护人员检查服务，不需要重复创建业务数据。

## 3. 个人资料、偏好和安全

### 个人资料

点击顶部姓名，可修改显示名称及启用的扩展资料。用户名不可在个人资料页修改。名称不能为空；保存成功后顶部姓名会更新。

头像支持 PNG、JPEG、GIF。上传后需保存资料才会采用新头像；“移除头像”也是先修改表单，再保存生效。文件不符合图片要求或上传失败时，按提示选择其他文件。

### 个人偏好

进入“个人偏好”，选择简体中文或 English、IANA 时区、浅色/深色/跟随系统主题，以及是否启用多标签、是否在刷新后保留标签，点击“保存”。

顶部语言和时区开关立即保存，偏好表单会同步这两个字段。主题等其他未保存的表单选择仍需点击“保存”。“恢复默认”会清除个人覆盖设置，回到账号或系统默认值。

时区示例：`Asia/Shanghai`、`America/Los_Angeles`、`UTC`。列表、日志和截止时间按当前时区显示；改变时区不会改变事情实际发生的时刻。夏令时由时区规则处理。

### 锁屏与密码

- “锁屏”锁住当前服务端会话；解锁需要当前密码。
- “修改密码”要求原密码、新密码和再次确认。新密码应符合页面/服务器规则，至少 12 个字符，最多 72 个 UTF-8 字节。
- 修改密码成功后需要重新登录，原会话会失效。
- 忘记密码时请其他有权限的管理员协助，不要把密码发到聊天或问题报告中。

## 4. 组织与权限

推荐配置顺序：部门 → 岗位 → 角色及数据范围 → 角色授权 → 用户及角色/岗位关系。

### 部门与岗位

部门支持上下级关系；岗位是独立列表。点击“新增”，填写名称、唯一编码、排序、启用状态等字段后保存。部门上级选择“无上级”表示根部门。

通过查询框筛选记录，按“查询”或回车执行。“刷新”重新读取当前列表。已被用户或其他对象引用的记录可能不能删除；部门也不能形成循环上下级。

### 角色和数据范围

角色表单中的数据范围决定用户能看哪些业务记录：

| 数据范围 | 含义 |
|---|---|
| 全部数据 | 当前租户和后台入口内的全部授权数据。 |
| 本部门及下级 | 账号所属部门及其下级部门的数据。 |
| 本部门 | 账号所属部门的数据。 |
| 仅本人 | 按业务表所有者/创建者规则限定为本人数据。 |
| 自定义部门 | 选择明确允许的部门。 |

多个角色的授权范围会合并，但始终受租户隔离限制。创建或修改角色后，使用“角色授权”选择该角色允许的目录、菜单和操作，再保存。勾选父项不代表自动拥有所有子操作；应检查具体勾选结果。

“查看用户”进入带角色筛选的用户列表。关闭列表中的“角色用户”标签可移除该筛选。超级管理员的默认权限不依赖某个普通角色，因此某角色下没有用户不等于管理员账号不存在。

### 用户管理

新增用户时填写用户名、显示名称、初始密码、部门、角色和岗位等信息。系统配置可以关闭部门、岗位或扩展资料字段。

编辑账号或修改账号关系可能使已有会话失效。具有权限的管理员可以重置允许管理的其他用户密码。当前账号和超级管理员账号受额外保护，列表不会对其展示普通编辑/删除/重置操作；本人资料和密码使用顶部入口修改。

### 权限资源

资源类型包括目录、菜单、按钮、逻辑权限。新增菜单还需填写访问路径和打开方式：

- 内部路由：本系统以 `/` 开头的路径，例如 `/iam/users`。
- 外部链接：在新窗口打开 `http://` 或 `https://` 地址。
- 内嵌页面：在受限制的 iframe 中打开网页；对方站点禁止被嵌入时无法正常显示。

菜单名称可以提供中文、英文翻译。内置资源的权限标识和类型不可随意修改，内置资源也不能删除。名称、隐藏状态及允许修改的配置按表单操作。

### 顶部导航

新增或编辑导航，填写名称、排序、启用状态，并选择它包含的一级菜单。可分别设置中英文名称。保存后顶部会显示相应入口；选择入口只过滤菜单，不会授予新权限。

## 5. 系统配置

### 数据字典

1. 选择字典类型，查看该类型下的字典项。
2. 在“字典类型”标签管理类型；点击一行可进入其字典项，点击行内“编辑”只打开类型编辑器。
3. 在“字典项”标签维护名称、值、排序和启停；多级类型还可指定上级项。
4. “检测并初始化”补充系统所需的内置字典，不是清空重建。

内置类型/条目的关键编码、固定值和部分状态受保护。业务功能依赖这些值，修改前应确认影响。显示名称可设置中英文翻译。

### 全局参数

“全局参数”和“参数分组”分开管理。常见分组为系统基础、安全、登录页面、界面设置、备案与版权。

参数值按类型编辑：布尔值使用开关，其他类型使用输入框。敏感参数不会在列表显示原值，编辑时留空表示保留原值。参数名称翻译和参数值是两回事。

“刷新缓存”让后续读取重新获取参数。“恢复默认”会覆盖内置参数值，影响所有使用这些参数的用户；在确认影响后再操作。会话时长变更主要影响之后签发的会话。

## 6. 安全管理与审计

- **在线会话**：按用户名查询会话，查看设备、IP、最后活动时间和状态。当前会话显示“当前会话”，其他会话可由有权限者强制下线。
- **登录日志**：按用户名、成功/账号密码失败/验证码失败和时间范围筛选；查看位置、浏览器和系统。本地/私网地址不会显示为公网地理位置。
- **关键操作日志**：按用户名、结果和时间范围筛选；显示动作、对象、耗时和时间。“查看对象”跳到相应业务页面，原对象已删除或权限改变时可能无法再打开。

日期筛选使用当前时区；结束时间是排他的边界。比如查询 10 日全天，应选择 10 日 00:00 到 11 日 00:00。

## 7. 文件中心

在“文件管理”按名称或文件类型查询。上传单文件不超过 20 MiB；图片需通过实际解码校验。点击文件名查看详情，符合条件的图片可以预览；使用“下载”取得文件。

文件始终校验租户和访问权限，不能通过猜测存储路径公开访问。被头像、通知等业务引用的文件可能无法删除，应先在引用它的业务页面解除引用。删除采用逻辑删除，列表不可见不代表磁盘文件立即清除。

## 8. 消息协同

### 系统通知管理

“消息协同 → 系统通知”是管理入口。按关键词、类型、优先级、接收范围查询；“回收站”开关切换正常通知和已回收通知。

发布步骤：填写标题 → 选择类型和优先级 → 选择接收范围及具体接收人 → 编辑正文 → 按需添加附件 → 保存。

接收范围支持全部可见用户、角色、部门、岗位、指定用户。“全部”仍受发布者的数据范围限制。系统保存发布时的接收人快照；新增用户不会自动成为旧通知接收人。

已读/接收人数可进入阅读情况。回收后通知不再按正常列表展示，恢复不会重置已经存在的阅读时间。批量操作前先勾选目标记录。

### 我的消息中心

顶部铃铛打开消息中心，包含系统通知、我的待办、私信。

- 通知：打开详情会记录已读；可筛选仅未读，也可对选中项或全部标记已读。
- 同步状态显示“实时同步”时使用实时连接；断线时可能显示“定时同步”，系统会补查消息。
- 角标汇总三类事项，处理后会更新。

### 待办

“我的待办”管理分配给本人的任务；“待办管理”供有权限的管理者查看并分配任务。两者可按关键词、状态、类型及时间范围筛选。

新建时必须填写标题和截止时间；管理分配还必须选择办理人。四种类型分别是无链接无内容、仅内容、仅链接、内容与链接。切换类型会决定需要填写哪些字段。第三方来源可选填来源系统、消息/流程 ID、来源链接和收发方标识。

状态包括未开始、进行中、已完成、已取消、未完成。已完成和已取消是终态，不能直接改回处理中；批量状态变更或删除前检查选中内容。

### 私信

选择收件箱或发件箱查看记录。“写私信”选择收信人并填写内容后发送，内容最多 10000 字符；也可以在已有消息中回复、查看会话。收发双方只能查看自己有权访问的消息。

## 9. 系统监控

| 页面 | 使用方式 |
|---|---|
| 服务器监控 | 查看 CPU、物理内存、JVM、线程、运行时间、连接池和磁盘；按需开启每 10 秒刷新。 |
| 缓存管理 | 查看各缓存条目数和命中情况；清理针对当前租户，系统不会展示缓存值。 |
| 事件发布管理 | 默认查看失败事件，可切换其他状态；只有失败且符合重试条件的事件能重投。重试可能执行实际业务副作用。 |
| 数据库文档 | 搜索表名或说明，选择表查看字段、主键和索引，可导出 Markdown 文档。无匹配表时显示空状态。 |
| SQL 执行统计 | 按 Mapper 语句标识搜索，点击调用次数、失败次数或耗时列排序；统计当前实例的实际执行，不展示 SQL 正文或参数。重置仅清空统计。 |

监控首次打开需等待采样或接口返回。应用重启会清空 SQL 内存统计；这不代表业务数据丢失。

## 10. 开放平台

“应用中心”管理外部调用方，普通使用者通常不需要操作。

1. 创建应用，填写名称、类型和说明，选择启用与签名要求。
2. 创建或轮换时才展示 AppSecret，一次性妥善保存；普通列表和详情不能再次查看它。
3. 调用方根据开发手册中的开放接口协议取得应用令牌。
4. “关联”记录对象类型、ID、名称，只是关联信息，不授予该对象的访问权限。
5. 轮换密钥会使旧应用令牌失效；应用更新也可能使旧令牌失效，修改后应让调用方重新认证。
6. 有关联对象的应用需先解除关联才能删除。

保留某个应用分类不代表已经实现该平台的业务集成。当前首版不含微信业务、报表设计器、打印设计器或 AI 数智化中心。

## 11. 常见问题

| 现象 | 处理 |
|---|---|
| 无权限、菜单缺失 | 检查当前账号、后台入口、角色和数据范围；由管理员分配权限后重新加载。 |
| 查询没有结果 | 检查关键词、角色/状态/时间筛选及当前时区；等待加载完成；数据也可能不在可见范围。 |
| 保存提示编码重复 | 换用未占用的编码，或先查询同名/同编码对象。 |
| 删除提示有子项或被引用 | 先处理子项或业务引用，不能强行跳过保护。 |
| 页面不存在 | 使用“返回首页”，从菜单进入，检查旧收藏地址。 |
| 登录失效或突然返回登录页 | 可能是会话过期、强退、改密或账号配置变化，重新登录后继续。 |
| 文件上传失败 | 检查大小、类型和网络；头像必须是真实可解码图片。 |
| 系统请求失败 | 记下时间、页面、操作步骤和错误文本，交给维护人员；不要反复点击有写入后果的按钮。 |

巡检记录中的“自动测试通过”不等于每个操作都已经在真实业务库执行。涉及真实通知、权限、密码、密钥和删除的最终操作，使用前应由负责人员确认对象及影响。
