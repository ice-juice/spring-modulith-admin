# 表格内部滚动与中部空间适配

用户要求：表格默认占满中部可用空间，数据增多只在表格内部滚动；只有显式约定才允许表格随页面增长。既有紧凑页头、背景品牌与顶部账号入口继续保持。

范围：frontend-next 公共 DataTable/滚动容器、管理壳与表格页面布局。保留请求、分页/排序、权限、列/密度偏好及业务操作；不修改后端或历史发布包。

设计约束：表格主体是唯一数据滚动区域；表头与列同步横向滚动并纵向保持可见。工具区和分页不被行数挤出视口。窄屏筛选条件过多时，工具区独立限高滚动，不能把表格撑出窗口。复合页面的多表各有有限的可用区域，不以行数无限撑高页面。显式自然展开作为公共组件的可选参数，默认不启用。
