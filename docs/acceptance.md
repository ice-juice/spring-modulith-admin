# 首版迁移验收

2026-11-10。以 [开发进度](development-progress.md) 的 P0～P4 和用户明确范围为准；JBolt 源码与闭源 SDK 的内部实现不要求逐行兼容。

## 功能对照

下表“自动验证通过”包括已列出的后端 MySQL/MockMvc/真实 WebSocket 或前端组件验证。它不代表用户已经完成登录后的人工浏览器验收。

最终标准 Maven Wrapper `verify`：101 项通过；前端类型/构建/ESLint、32 项 Vitest、10 模块双语言校验通过；Node.js 签名客户端 3 项通过。运行中的开发服务健康 UP，22 类受保护入口均验证中英文匿名 401。浏览器验证受保护 SQL 页面深链进入登录页并保留 redirect。

## 明确不在本期

- UReport 报表设计器与查看权、微信公众平台、七牛账号/Bucket、敏感词词库、代码生成平台。
- hiprint 打印设计器、AI 数智化中心：用户明确另期开做。
- 多数据库、租户开通/SaaS 管理、对象存储、集群消息分发：保留接口或数据兼容基础，未宣称已实现。
- 关联对象只迁移元数据与删除保护，不对被排除的微信等平台建立业务集成。

## 人工浏览器验收待办

先使用用户自行设置的管理员账号登录 [本地前端](http://127.0.0.1:5173/)。Browser Runtime 要求密码/验证码由用户本人输入；Agent headless 页面不能自动升级为用户可见 IAB。需要用户明确要求切到内置浏览器并完成认证后，才继续受保护页面巡检。

最后只读检查确认开发库尚无管理员。先在项目根目录运行 `pwsh -NoProfile -File tools/dev/start-with-admin.ps1`，本地隐藏输入初始密码；该脚本只在没有管理员时通过现有应用启动逻辑创建 admin，不重置已有账号。无需把密码发到聊天里。

1. 中英文切换、主题、时区和多选项卡；刷新后偏好保留。
2. 创建部门/岗位/角色/用户，分配权限，用受限用户核对菜单、操作按钮和数据范围；查看角色用户。
3. 个人资料、头像上传/移除；文件上传、下载、删除及引用保护。
4. 创建通知、选择五类受众、附件、阅读统计、回收与恢复。
5. 待办创建/分配、截止时间、状态切换；两个用户互发私信，检查消息角标与强退。
6. 查看监控、缓存、SQL、事件与数据库文档页面；以人工下载检查导出文件。
7. 创建应用、保存一次性密钥，用参考客户端调用开放接口，验证轮换后旧令牌失效。
8. 操作台统计、快捷入口、通知/待办与操作日志详情回跳。

## 运行边界

MySQL 当前运行在 Windows 临时实例；WSL 尚未启用，需要管理员启用和重启，步骤见 [环境文档](dev-environment.md)。这不影响上述本机 MySQL 自动验证，但不能将其写成 WSL 已验收。

管理员会话和应用令牌为数据库持久化；验证码、认证限流、WebSocket 票据/连接、SQL 指标为单实例内存。生产部署须配置数据库备份、上传目录和应用主密钥持久化，见 [部署说明](deployment.md)。
