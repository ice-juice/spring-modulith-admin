# 规则模板示例

示例位于新版界面的创建流程，供开发和专业实施人员起步使用。它们不会自动安装到租户、发布或绑定业务对象。页面沿用当前菜单权限，运营仍从模板目录选用已经发布的固定版本。

## 使用步骤

1. 进入“规则中心 → 规则场景 → 新增场景”，选择“示例场景”。检查字段与参数约束，按项目需要修改唯一编码、名称，再保存。替换未保存配置会要求确认，也可选择空白场景自行设计。
2. 进入“规则模板 → 新增模板”，选择刚建立的场景，再选择“示例模板”。仅显示输入、输出、参数策略相容且场景允许的类型；自定义契约继续使用空白模板。
3. 填写模板编码与名称，打开编辑页。查看规则和参数说明，明确点击“保存草稿”才创建模板；保存不会发布。
4. 打开“模拟与解释”，从“示例输入”选一组并点击“载入示例数据”，再模拟。载入只替换当前面板输入，不执行、不写业务数据，也不保存真实试算输入到浏览器存储。
5. “发布断言”页提供每组示例的完整输入、参数和期望输出。发布时后端验证全部断言，失败则保留原生效版本。新模板发布后才进入运营目录。

## 四类示例

| 示例 | 编辑方式 | 规则与默认参数 | 边界断言 |
| --- | --- | --- | --- |
| 比例折扣 | 表达式 | `round(input.amount * params.ratio, 2)`；默认比例0.9 | 100→90，0→0；19.99按0.85计算→16.99 |
| 会员资格 | 条件 | 会员且金额达到门槛；默认门槛100，返回布尔值 | 会员100→true，会员99.99→false，非会员200→false |
| 满额减免 | 流程 | 判断门槛，命中减免并保底0，否则原价；默认门槛100、减免10 | 100→90，99.99→99.99；门槛0、减免10时5→0 |
| 阶梯优惠 | 决策表FIRST | 高档200按0.8，低档100按0.9，其余原价；返回payable和rate | 200→160/0.8，100→90/0.9，99.99→99.99/1 |

金额输入非负、最多两位小数；比例0～1、最多四位小数。货币计算采用后端精确十进制，四舍五入为HALF_UP。会员资格未命中时返回NOT_MATCHED及false，属于正常业务结果。阶梯表按高档、低档、原价的行序选择首个命中，使用者应保持高档门槛大于低档；这是示例配置要求，当前不宣称具备跨参数关系约束。

阶梯表保留原价兜底行；为满足默认输出契约，应付金额字段允许为空。如果修改行结构导致未命中，默认返回NOT_MATCHED和 `{payable:null,rate:1}`，表示无法报价，不能将其当作零元价格。正常的三档输出均有明确应付金额。

本示例明确了计算口径，仅用于演示四类编辑方式。不包含多优惠叠加、税费、币种换算、退款分摊或真实商品绑定；接入业务对象仍须由其所属模块提供RuleBindingPolicy授权。实际验证结果和当前状态见[体验补齐进度](authoring-followup.md)。
