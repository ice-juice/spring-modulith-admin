# 可视化规则流程编排：交互补齐方案

2026-11-11。依据P06、implementation-plan的RE2和用户继续实施授权，归属基座通用规则能力，沿用main上的 `frontend-next/src/features/rule/`、Vue Flow、Monaco和已有FLOW契约。本次补充现有设计的交互细节，不调整模块架构、目录归属、数据库或后端执行协议。

## 目标及当前缺口

开发和专业实施人员通过组件库拖拽、连线、表单及字段引用完成自定义规则。运营继续选用已发布模板。当前已有画布、连线、节点追踪及编辑历史，但节点添加依赖下拉按钮；结构化判断、SWITCH分支、输出类型和子规则映射主要依赖JSON，不能视作完整可视化编排。

## 界面和数据设计

- 桌面按“组件库 → 画布 → 节点配置”排列。组件提供计算、条件、选择、子规则、决策表、返回结果；开始节点唯一，随流程创建。拖到画布使用当前缩放和平移后的坐标；点击组件提供键盘和触屏替代，不自动接线。最多64节点。窄屏顺序排布，禁止横向撑开页面。
- 画布支持选中、拖动、缩放、整理、拖线，点击连线后明确断开；属性区也提供出口选择/清空。条件显示真/假，选择显示各匹配值及默认出口。所有连接入口复用同一校验：禁止自连、指向开始、无效出口、缺失节点和环。删除节点确认后清理入边；开始不可删除。
- 画布坐标、选择、缩放是当前编辑会话的展示状态，不写入执行文档；节点ID稳定，既有文档原样可读。重新加载按节点列表生成初始布局。领域图编辑复用当前页撤销/重做，不承诺坐标持久化或位置撤销。
- 开始节点展示模板已有输入字段、参数及最终输出契约。场景契约已冻结，不能在某个流程节点偷偷扩展输入；参数在模板契约页按原策略配置。
- 计算节点：表达式或字段引用输入，表单定义输出类型、必填与对象子字段，输出通过 `context.steps.<节点ID>`供后继节点引用。可选字段仅含全局input/params和保证执行的前驱结果，分支另一侧结果不提供为可用输入。
- 条件节点：明确在“条件构建器/布尔表达式”间切换，切换有内容替换确认。构建器支持AND/OR/NOT、比较、空值与集合运算，字段选择和常量输入；真/假出口分别配置。保存只能包含condition或expression之一，复用现有只读条件语义。
- 选择节点：表达式返回匹配值；逐行配置唯一匹配key和出口，最多16行，另设默认出口。重命名/删除立即更新端口和连线，不通过JSON才能维护分支。
- 子规则/决策表节点：按已授权模板及不可变版本选择，决策表节点只接受DECISION_TABLE版本。显式“应用此版本”后同步输出契约，逐字段映射child input/params到父级字段、前驱输出、常量或受限表达式；保留字符串ID，绝不自动追随最新版本。列表分页明确，已保存但无权读取的版本ID保留，不因下拉无结果清空。换节点/版本的迟到响应丢弃。
- 返回节点：选择现有字段/前驱结果或编写表达式，输出必须满足流程最终契约。结构化对象仍由受限表达式产生，不增加任意脚本或业务写副作用。表单旁展示最终类型和可用引用。
- 所有节点保留折叠的高级JSON兼容入口，但主要操作不依赖JSON。表单本身的无效输入阻止保存；服务器图/类型/引用校验为最终依据。非法图可在本地编辑中存在，模拟/发布必须通过服务端；前端结构提示不能冒充完整执行验证。

## 安全与兼容

复用既有菜单/操作权限、租户、数据范围、保存修订和发布门禁，不新增自动授权；只读和保存期间禁止修改。专业查询只用既有templates/versions接口。没有真实业务绑定适配器仍拒绝对象绑定。模拟不写业务数据，变更清除旧结果，超时不盲重试。双语、主题、键盘、触屏和无损十进制继续生效。

## 实际发现与修正

- 拖线原来检查成环，出口表单直接赋值可绕过；现统一连接函数，并拒绝开始目标、未知源节点和无效端口。
- 原条件节点有结构化condition时没有表单显示；现复用条件构建器，模式切换保证condition/expression互斥。选择分支和对象字段重命名采用局部输入缓冲，避免父级输入/历史刷新把未提交内容还原。精确数值输入允许暂时的`0.`并保留全部小数位，非法值不能通过表单。
- 条件栏最初按页面宽度分成两列，窄栏被挤压；已使用容器宽度布局，复查截图及产物浏览器通过。
- 首次开发模式真实联调已保存完整图但模拟面板状态中途丢失，无法确认是否为并行热更新导致，该运行不计验收；增加静态真实测试入口、逐响应检查后，固定产物联调通过。失败日志`rule-visual-flow-real.log`保留。
- 最终verify过程中并行新增的富文本安全测试曾失败；其所属修改转入真实浏览器验证后，本轮重新执行完整门禁通过。此处不宣称已重新验收其他模块的全部真实浏览器行为。

生产负载、恢复演练、实际商品授权绑定、跨环境/多节点一致性和RE5功能仍属于独立验收；本次没有据本地模拟或静态页面200声称这些能力。
