# 新前端设计规范 v2 · 柔光工作空间

日期：2026-11-11。用户确认主色：鸢尾紫。适用版本：frontend-next v0.2.0。实际实施和逐阶段验收见 [重构进度](softlight-progress.md)，页面对应见 [覆盖清单](softlight-coverage.md)。原设计提案及独立样板保留于 `design-review-softlight/`，不当作正式页面验收证据。

## 视觉语言

图标支持线性与3D双图库。导航中的3D图标24px、线性18px，按钮配置图标18px，选择器大预览40px；不扩大导航行高。3D使用透明WebP、本地加载，与三套皮肤和明暗主题共存。选择器支持中文/英文名称、稳定ID搜索及八类筛选，每页最多48个结果，显示实际菜单/按钮效果。默认按钮图标只有管理员明确配置才覆盖，none表示主动不显示。详细素材授权和验收见 [图标设置](icon-settings-progress.md)。

皮肤与主题分离：iris / celadon / amber 三套皮肤，各支持 light / dark / system。默认 iris。浅色主色分别为 #6b55c7 / #286b59 / #895925，深色分别为 #b7a4ff / #91cfb4 / #e3b879；正文语义色保持可读，所有浅色皮肤主功能区均为 #f6f7fa。皮肤同时调整选中态、标签栏、焦点、柔光插画等语义变量，禁止硬编码颜色导致另一套皮肤仍出现紫色装饰。详情与实际截图见 [皮肤与主题进度](skin-theme-progress.md)。以下色表为默认 iris。

雾白背景、石墨文字、鸢尾紫行动色，以排版与留白区分信息轻重。柔光与玻璃主要用于品牌场景、欢迎区及少量辅助表面；高频表格、表单、权限正文采用实色。Lucide 操作图标统一，原创 CSS 轨道图形只作装饰。

## 排版、空间与响应式

搜索统一至顶部，不占用侧栏菜单高度。桌面入口显示搜索文字和快捷键，窄屏显示图标。弹窗采用紧凑标题、输入、菜单/全局模式切换、按来源分组的可滚动结果；底部仅提供键盘提示。空态、加载、失败与更多结果按来源独立显示。延续三皮肤/明暗主题，320px下不横向溢出，极窄顶部隐藏重复页面标题以保留搜索和账号操作；主页面h1继续显示。

- 正文 14px，次级信息 12px，管理页头 18px，主要指标约 30–34px；数字使用等宽数字。
- 常用控件高度 40px，小按钮保留原使用场景；粗指针环境最小点击区域规则继续生效。
- 控件圆角约 8–10px，内容表面 16px，品牌区域 20px；阴影克制。
- 桌面页面水平边距 32px、纵向 16px，窄屏均为 16px。桌面侧栏 240px，收起 76px；小于 lg 使用既有 Reka Sheet 抽屉。
- 顶栏按实际内容容器宽度收起快捷搜索和账号文字，覆盖 CSS 200% 缩放，不仅依靠视口媒体查询。
- 表格横向滚动限于容器；编辑容器正文滚动、标题与操作区可见；数据表保留标准/紧凑密度和用户隔离偏好。
- 颜色与状态反馈通常约 150–220ms；减少动态效果下禁用位移/平滑滚动与非必要动画。本版无持续光场、WebGL 或新增动效依赖。

## 管理壳与导航

侧栏顶部的导航组切换器承接原顶部业务导航栏。分组来自原 `navigation` 协议，名称来自服务端，只筛选已授权菜单；支持嵌套菜单保留祖先、空分组与分组失效回退。它不切换租户或组织。

分组选择使用 `sma.next.navigation.v1.<portal>.<userId>` 会话存储；搜索词不持久化。侧栏收起和手机抽屉仍可切组。Ctrl/Cmd+K 聚焦菜单查询。

工作标签继续独立显示，保留开关、关闭、路由去重与刷新恢复。旧 `sma.theme`、语言/时区、表格和标签偏好键不迁移或清空。锁屏、改密、登出、品牌配置、头像与消息连接生命周期保留。版权/备案链接保留在登录页，管理区底部品牌采用不占位的背景标识。

## 实际页面

- 工作台：柔光欢迎区、按实际数量自适应排列的 API 指标、待办/快捷入口和运行上下文。没有趋势 API，故不引入样板中的虚构趋势图或增长率。
- 用户：成员概览、头像首字、统一筛选/数据表。总数取真实分页结果，启用数明确标为“当前页”；列 ID、搜索、密码重置与编辑契约保持。
- 角色：默认左侧角色列表、右侧权限工作区，顶部保留资料编辑/查看用户/删除。独立勾选、数据范围、隐藏选择、禁用节点保持；切换与离开保护草稿，写入失败保留勾选，迟到响应隔离。
- 登录：品牌叙事/轨道图形与表单分栏，移动端压缩品牌区；服务端品牌背景、验证码刷新、失败保留、安全跳转及凭据处理保留。
- 其他页面：共同页头/双语模块说明、表格与编辑组合；监控指标、数据库主从、消息概览、资料/偏好、错误及嵌入页面另有适配，详见逐路由清单。

## 背景品牌与数据空间

管理壳背景采用三个层次：顶部导航、工作标签栏、主内容底色。按最新反馈，浅色为白色顶部、淡紫标签栏、原浅灰主功能区（#f6f7fa），主功能区不使用紫色底；深色仍从较亮紫灰逐层加深。表格与表单保留实色。选中工作标签单独提亮，并以鸢尾紫文字标识；层级不占用额外高度。使用 `--shell-*` 变量统一管理，颜色与当前截图见 [背景层次记录](shell-color-progress.md)。

管理壳取消独立 footer、分隔线与原有页脚 padding。品牌名相对内容区底部居中绝对定位（层级 0），主内容区位于层级 1；透明内容背景可透出品牌，实色表格/功能卡片自然覆盖。品牌使用主题次级色、12px 装饰文字，`pointer-events:none`、不可选择且标记 aria-hidden，不成为交互或阅读障碍。主内容不为品牌额外留白。900px 高桌面样例释放约 67.66px 高度，长表格覆盖和深色手机检查见 `background-brand-validation.json` 与 `images/background-brand-*.png`。

## 表格填充与内部滚动

标准数据列表以可视窗口剩余高度为边界，标题、筛选与数据区纵向排列。数据区填满中部；数据变多只增加表格内部滚动距离，不推动整页或分页。少量及空数据维持相同外框。表头纵向吸顶、横向随列同步；列工具和分页固定在滚动区域之外。换页、改变页大小和排序回到数据顶部，保留横向位置。

公共 `TableWorkspace` 将工具区限为可用高度的 45%，超出时独立滚动，剩余区域交给表格；发布控制台工具较多，限制为 35%。工具区可键盘聚焦。管理壳通过直属工作区或路由 `contentLayout: 'table'` 启用固定高度，并响应窗口、可视视口及 CSS 缩放变化。自定义分页使用 `#footer`。

数据库左侧表清单独立滚动，右侧字段/索引共用标签区域；手机上清单压缩至最多 120px。仪表盘等复合页面中的独立 DataTable 默认限高，避免数据行数无限撑高页面。只有明确要求自然展开的页面才能显式设置 `scroll-mode="page"`，不能因为窄屏或数据多自动退回整页滚动。
