## 构建结构

新增根 Maven reactor；`extension-sdk` 为无外部依赖的插件契约，`extension-protocol` 为宿主与安全服务共享的数据及校验工具。`backend` 仍是业务宿主，签名私钥不会加入宿主。后续加入独立安全服务和隔离构建执行器。
