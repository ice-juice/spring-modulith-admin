# 开发进度

本文是 Springboot Modulith Admin 的开发总控文档：按 P0～P4 分阶段迁移 JBolt 的产品能力（功能地图见 [jbolt-product-design.md](jbolt-product-design.md)）。**每个功能开发完成后，先执行第 2 节的验证，全部通过才把状态改为“完成”并写入第 4 节的验证记录，然后进入下一项。**

状态：⬜ 未开始 ｜ 🟦 进行中 ｜ ✅ 完成（已验证） ｜ ⛔ 阻塞

## 1. 范围

**纳入本版本**：JBolt 的组织权限、登录会话、系统配置、审计日志、消息协同、文件、系统监控、开发文档（数据库文档）、开放平台应用中心、操作台；新增多语言、多租户字段、数据权限、多后台入口（`portal`）、UTC 时间与用户时区。

**本版本不做**（需求确认）：UReport 报表设计器、微信公众平台、七牛账号、敏感词词库、代码生成平台。

**另期开发（2026-11-10 用户确认）**：hiprint 打印设计器、AI 数智化中心（JBolt 实现依赖闭源 SDK）。先完成既有 P0～P4。
